# Burbank Police Calls for Service

Reports from Burbank PD’s public dispatch log: June 24, 2024 through September 8, 2026.

**Live:** https://pfaustino.github.io/burbank-police-incidents/

```bash
npm install
npm run data   # rebuild public/data from the TSV
npm run dev    # http://localhost:5173/
```

This is a dispatch log, not a crime report. Traffic stops, alarms, and information calls are counted even when no crime is confirmed.
